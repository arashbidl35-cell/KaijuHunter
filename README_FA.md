# Kaiju Hunter — نسخهٔ اولیهٔ پروژهٔ اندروید

این پروژه یک نمونهٔ اولیهٔ اندرویدی است؛ APK آماده در این محیط ساخته نشده است. سرویس دسترس‌پذیری فقط دنبال متن دقیق «حریف بعدی» می‌گردد و فقط همان دکمه را کلیک می‌کند. اگر این دکمه در دو بررسی پیاپی دیده نشود، اتوماسیون خاموش می‌شود تا ایونت یا صفحهٔ غیرمنتظره به‌صورت دستی بررسی شود. این نسخه گزینه‌های ایونت را خودکار انتخاب نمی‌کند.

## ساخت APK

نیازمندی‌ها:
- Android Studio جدید (پیشنهاد: نسخه‌ای که Android Gradle Plugin 8.7.3 را پشتیبانی کند)
- JDK 17 یا 21
- Android SDK Platform 35 و Build Tools متناظر

مراحل:
1. فایل ZIP را استخراج کنید.
2. Android Studio → Open و پوشهٔ `KaijuHunter` را انتخاب کنید.
3. اجازه دهید Gradle Sync انجام شود. در صورت درخواست، Gradle و SDK را نصب کنید.
4. از منوی Build گزینهٔ **Build APK(s)** را انتخاب کنید.
5. APK آزمایشی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نصب و استفاده
1. APK را روی گوشی نصب کنید.
2. برنامهٔ Kaiju Hunter را باز کنید.
3. دکمهٔ «باز کردن تنظیمات دسترس‌پذیری» را بزنید و سرویس Kaiju Hunter را فعال کنید.
4. به برنامه برگردید و «شروع / ادامهٔ شکار خودکار» را بزنید.
5. تلگرام را باز کنید و وارد پیام شکارگاه Kaiju Legends شوید.
6. ابتدا با نظارت خودتان آزمایش کنید. سرویس با فاصلهٔ حداقل ۱٫۸ ثانیه فقط دکمه‌ای را کلیک می‌کند که متن دسترس‌پذیری آن دقیقاً «حریف بعدی» باشد.
7. اگر دکمه ناپدید شود، سرویس متوقف می‌شود. ایونت را دستی کامل کنید، سپس برنامهٔ Kaiju Hunter را باز کنید و «شروع / ادامهٔ شکار خودکار» را بزنید.
8. برای توقف فوری، برنامه را باز کنید و «توقف اضطراری» را بزنید؛ همچنین می‌توانید سرویس دسترس‌پذیری را از تنظیمات اندروید خاموش کنید.

## محدودیت‌های مهم
- این پروژه هنوز در این محیط کامپایل یا روی دستگاه واقعی آزمایش نشده است.
- اگر Telegram متن دکمه را در درخت دسترس‌پذیری نشان ندهد، کلیک انجام نمی‌شود. اگر زبان رابط متفاوت باشد یا متن دکمه تغییر کند، باید متن هدف را در `HunterAccessibilityService.java` تنظیم کنید.
- برای ایمنی، نبودن دکمهٔ «حریف بعدی» باعث توقف می‌شود؛ بنابراین ادامه پس از ایونت فعلاً با فشردن دکمهٔ شروع در اپ انجام می‌شود، نه کاملاً خودکار.
- نسخهٔ فعلی به تصویر/ضبط صفحه نیاز ندارد و از OCR استفاده نمی‌کند؛ این باعث می‌شود نیاز مجوزهای آن کمتر باشد. مجوز دسترس‌پذیری همچنان حساس است: آن را فقط برای این پروژهٔ مورداعتماد فعال کنید.
- برنامه هیچ دکمهٔ «حمله» را جست‌وجو یا کلیک نمی‌کند.

## ساخت APK با GitHub Actions (بدون کامپیوتر)

فایل `.github/workflows/build-apk.yml` برای ساخت خودکار APK اضافه شده است. پس از قرار دادن **محتویات پوشه پروژه** در یک مخزن GitHub:

1. وارد صفحه مخزن در GitHub شو و تب **Actions** را باز کن.
2. گردش‌کار **Build Kaiju Hunter APK** را انتخاب کن.
3. روی **Run workflow** و سپس دکمه سبز **Run workflow** بزن.
4. پس از پایان موفق اجرا، همان صفحه اجرای workflow را باز کن و پایین بخش **Artifacts**، فایل `KaijuHunter-debug-apk` را دانلود کن.
5. ZIP مربوط به Artifact را در گوشی استخراج کن؛ فایل `app-debug.apk` را باز و نصب کن. اگر اندروید اجازه خواست، فقط برای برنامه‌ای که با آن فایل را باز می‌کنی مجوز **Install unknown apps** را فعال کن.

این ساخت، APK آزمایشی (debug) می‌سازد و امضای انتشار فروشگاهی ندارد. پروژه هنوز روی دستگاه واقعی آزمایش نشده است.
